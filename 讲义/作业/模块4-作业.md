# 模块 4：现代前端 — 课后作业

---

## 基础题（必做）

### 1. 模块化练习

创建以下文件结构的项目，用 Vite 启动：

```
src/
├── main.js        —— 入口，导入其他模块并调用
├── math.js        —— 导出 add、subtract、multiply、divide
└── string.js      —— 导出 reverse、capitalize、truncate
```

要求：
- 使用 ES Module 的 `import` / `export`
- `math.js` 使用命名导出，`string.js` 使用默认导出 + 命名导出混合
- 在 `main.js` 中正确导入并测试所有函数

### 2. React 组件练习

用 `npm create vite@latest` 创建一个 React 项目，创建以下组件：

| 组件 | Props | 功能 |
|------|-------|------|
| `Header` | `title`, `links[]` | 显示标题和导航链接列表 |
| `Card` | `title`, `description`, `image?` | 渲染一张卡片 |
| `Footer` | `copyright` | 显示版权信息 |

在 `App.jsx` 中组合这些组件，形成完整页面。

### 3. 数据驱动界面

在项目中添加一个使用 `useState` 的功能。以下任选其一：

- **评论列表**：可以输入新评论并添加到列表
- **计数器**：+1 / -1 / 重置，数值不能为负数
- **Todo 列表**：添加、标记完成、删除

要求：
- 使用 `useState` 管理数据
- 正确使用不可变更新（`[...old, new]` 而不是 `.push()`）
- 列表项使用 `key` prop

### 4. Next.js 项目

用 `npx create-next-app` 创建项目，要求：
- 创建至少两个页面（首页 `/` + 关于页 `/about`）
- 页面之间通过 `<Link>` 组件导航
- 提取一个共用的 `Layout` 组件（包含 Header + Footer）

## 进阶题（选做）

### 5. useEffect 练习

创建一个实时显示当前时间的组件：
- 使用 `useEffect` 设置定时器
- 组件卸载时清除定时器（return cleanup function）
- 时间格式：`2026年7月28日 14:30:45`

### 6. Next.js 部署

将你的 Next.js 项目通过以下两种方式之一部署到服务器：
- 方案 A：`output: "export"` 静态导出 + Nginx 托管
- 方案 B：`next start` + pm2 进程守护 + Nginx 反向代理

## 挑战题

### 7. 从零实现小型 React 应用

创建一个完整的 Todo 应用，包含以下功能：
- 添加新的 Todo
- 标记 Todo 为完成/未完成
- 删除 Todo
- 显示"剩余 X 项未完成"
- 按完成状态筛选（全部/未完成/已完成）
- 使用 `useState` 管理全部数据状态

要求：
- 组件化：拆分出 `TodoItem`、`TodoList`、`AddTodo`、`FilterBar` 等组件
- 不依赖任何 UI 库，纯自己写
- 数据持久化到 `localStorage`

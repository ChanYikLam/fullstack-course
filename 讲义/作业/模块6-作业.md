### 2. SQLite 练习

用 Python 的 `sqlite3` 模块创建一个"图书管理"数据库：

```sql
-- 表结构
CREATE TABLE books (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    author TEXT NOT NULL,
    year INTEGER,
    rating REAL
);
```

要求：
- 插入至少 5 本书的数据
- 实现：查询所有书（按年份排序）
- 实现：查询评分 > 8.0 的书
- 实现：更新某本书的评分
- 实现：删除某本书

### 3. SQLAlchemy 迁移

用 SQLAlchemy 重写上面的图书管理功能，要求：
- 定义 `Book` 模型类
- 用 ORM 方式实现 CRUD
- 对比 SQLite 手写 SQL 和 ORM 两种方式的代码量和安全性，写一段对比分析

### 4. 前后端联通

- 创建 FastAPI 后端（提供 `/api/books` 接口，从 SQLite 读取数据）
- 创建 React 前端（展示图书列表，含加载中和错误状态）
- 前端从后端获取数据并展示

## 进阶题（选做）

### 5. JWT 实现完整的用户系统

实现以下接口：

| 接口 | 方法 | 要求 |
|------|------|------|
| `/api/auth/register` | POST | 用户名+密码 → bcrypt 哈希 → 存入数据库 |
| `/api/auth/login` | POST | 验证密码 → 返回 JWT token |
| `/api/auth/me` | GET | 携带 token → 返回当前用户信息 |
| `/api/auth/change-password` | PUT | 携带 token → 验证旧密码 → 更新新密码 |

前端实现登录表单和 token 管理（存 localStorage，每次请求带 `Authorization` 头）。

### 6. 分页实现

给 `/api/books` 接口添加分页参数 `?page=1&size=10`，返回格式：

```json
{
    "items": [...],
    "total": 100,
    "page": 1,
    "size": 10,
    "pages": 10
}
```

# 模块 8：上线运营 — 课后作业

---

## 基础题（必做）

### 1. 域名配置

- [ ] 注册一个域名
- [ ] 配置 DNS A 记录指向你的服务器 IP
- [ ] 通过域名访问到你的网站（截图浏览器地址栏）

### 2. HTTPS 配置

- [ ] 用 Certbot 为你的域名配置 HTTPS
- [ ] 确认浏览器显示锁图标（截图）
- [ ] 验证 HTTP 自动重定向到 HTTPS

### 3. 进程守护

为你的后端（FastAPI）创建 systemd 服务文件，要求：
- [ ] 开机自启
- [ ] 崩溃自动重启（Restart=always）
- [ ] 正确使用虚拟环境路径

提交 `.service` 文件内容，并测试以下操作：
1. `sudo systemctl status myapp` → 截图运行状态
2. `sudo systemctl stop myapp` → 用 curl 验证服务不可访问
3. `sudo systemctl start myapp` → 服务恢复，curl 验证可访问

### 4. 日志

- [ ] 在 FastAPI 中将 `print` 替换为 `logging`（使用 INFO 级别）
- [ ] 配置日志输出到文件（带 RotatingFileHandler，10MB 轮转）
- [ ] 在 Nginx 中找到 access.log，用 `tail -f` 查看实时访问日志并截图

## 进阶题（选做）

### 5. Nginx 反向代理

配置 Nginx 反向代理：

```
www.yourdomain.com → localhost:3000（Next.js 前端）
api.yourdomain.com → localhost:8000（FastAPI 后端）
```

要求：
- 两个子域名都配置 HTTPS
- 正确设置 `proxy_set_header`（Host、X-Real-IP、X-Forwarded-For、X-Forwarded-Proto）
- 上传文件大小限制：`client_max_body_size 10M`

### 6. 自动部署

创建 GitHub Actions workflow，实现 `git push` → 自动部署：

- [ ] 创建 `.github/workflows/deploy.yml`
- [ ] 配置 GitHub Secrets（SERVER_HOST、SERVER_USER、SERVER_SSH_KEY）
- [ ] 服务器上生成 SSH 密钥对，公钥添加到 `authorized_keys`
- [ ] 测试：本地 push → 查看 Actions 运行状态 → 确认部署成功

## 挑战题

### 7. 完整的运维体系

**搭建完整的运维体系，要求**：

1. **服务管理**：所有服务都由 systemd/pm2 管理，确认 `systemctl enable` / `pm2 startup`

2. **日志轮转**：为应用日志配置 logrotate（周轮转，保留 4 周）

3. **自动部署**：
   - GitHub Actions 自动部署
   - 部署失败时发通知（可选：邮件、钉钉、企业微信、Telegram）
   - 部署脚本包含 `pip install`（处理新依赖）

4. **编写运维手册**（`OPS.md`），记录：
   - 服务器基本信息（IP、域名、厂商）
   - 各服务的启动/停止/重启/查看日志命令
   - 各配置文件的位置
   - 日志文件的位置
   - 常见问题和解决方案
   - 紧急回滚步骤

5. **压力测试**：
   - 手动停掉后端服务 → 确认 systemd 自动重启
   - 重启服务器 → 确认所有服务自动恢复

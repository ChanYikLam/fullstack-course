# 模块 3：前端基础 — 课后作业

---

## 基础题（必做）

### 1. 制作个人主页

创建包含以下内容的网页：
- 你的名字（大标题 `<h1>`）
- 一段自我介绍（段落 `<p>`）
- 你的技能列表（`<ul>` / `<li>`）
- 至少一张图片（`<img>`）
- 一个外部链接（`<a href="...">`）

要求：
- 将 HTML、CSS、JS 分离到三个文件
- 用 CSS 美化页面（至少用到：颜色、字体、边距、边框、阴影）

### 2. Git 练习

将上面的项目初始化为 Git 仓库，至少做 3 次有意义的提交：

1. 第一次提交：HTML 结构
2. 第二次提交：添加 CSS 样式
3. 第三次提交：添加 JS 交互

每次提交都要有明确的 commit message。创建 `.gitignore` 文件。

### 3. GitHub 推送

- 在 GitHub 上创建仓库
- 关联本地仓库并推送
- 在另一个目录 `git clone` 下来，确认文件完整

### 4. 服务器部署（截图验证）

- [ ] 在服务器上 `git clone` 你的代码
- [ ] 修改 Nginx 配置指向你的项目目录
- [ ] 通过公网 IP 访问到你的个人主页
- [ ] 截图浏览器中的页面

---

## 进阶题（选做）

### 5. CSS 深入学习

- 学习 Flexbox 布局，用 Flexbox 重新布局你的页面
- 学习 CSS 变量（`--primary-color: #3498db;`），用变量统一管理配色
- 实现一个响应式布局：在手机上也能好看

### 6. JavaScript 交互

给你的页面添加一个"暗黑模式"切换按钮：
- 点击按钮切换页面的背景色和文字颜色
- 用 `localStorage` 记住用户的偏好（刷新后保持）

### 7. Git 进阶

- 学习 `git branch` 创建分支
- 在分支上做修改，然后 `git merge` 合并回 main
- 故意制造一次合并冲突，学习如何解决

---

## 挑战题

### 8. 多个页面

- 创建第二个 HTML 页面（比如"项目展示"页）
- 两个页面之间通过链接互相关联
- 修改 Nginx 配置支持多页面访问
- 统一两个页面的导航栏（复制或用 JS 动态生成）

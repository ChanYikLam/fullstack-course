## 课前阅读（15 分钟）

### 你真的"会"用电脑吗？

你会用微信、会打开浏览器、会编辑 Word 文档。但你知道你电脑里的文件到底放在哪里吗？

打个比方：
- **图形界面（Desktop）** = 你站在商场里用导航屏找店铺
- **终端（Terminal）** = 你手里拿着精确的门牌号和楼层图

当你需要精确操控文件、登录远程服务器时，图形界面就像一个翻译——它能做的事有限。而终端让你直接和电脑对话。

### 互联网的关键问题

你在浏览器输入 `bilibili.com` 按下回车。这个简单动作的背后，发生了非常复杂的事情。但这个模块结束后，你应该能用几句话把整条链路说清楚。

## 第 1 节：认识你的电脑

**视频**: [B 站链接](https://www.bilibili.com/video/BV1zcRhBsEob) | **时长**: ~19 分钟

### 详细讲解

#### 1.1 文件系统的树状结构

电脑里的所有文件，都挂在同一个"根"下面。就像一棵倒过来的树：

```
/  (根目录——一切从这里开始)
├── bin/        (系统程序)
├── etc/        (配置文件)
├── home/       (用户的家)
│   └── yourname/
│       ├── Desktop/    (桌面)
│       ├── Documents/  (文档)
│       └── Downloads/  (下载)
├── tmp/        (临时文件)
└── var/        (日志、缓存)
```

#### 1.2 绝对路径 vs 相对路径

| | 绝对路径 | 相对路径 |
|------|----------|----------|
| 像什么 | 完整的邮寄地址 | "往前走两个路口右转" |
| 特点 | 从根目录 `/` 开始写 | 从当前位置开始写 |
| 例子 | `/home/zhangsan/Documents/report.txt` | `./report.txt` 或 `../images/photo.jpg` |
| 什么时候用 | 需要精确指定位置时 | 在项目内部引用文件时 |

> `..` = 上级目录  
> `.` = 当前目录  
> `~` = 你的家目录（等同于 `/home/你的用户名`）

#### 1.3 macOS vs Windows 路径差异

```bash
# macOS/Linux 路径
/Users/zhangsan/Documents/hello.txt     # 用正斜杠 /

# Windows 路径
C:\Users\zhangsan\Documents\hello.txt   # 用反斜杠 \，还有盘符 C:
```

### 课堂演示代码

打开终端，跟着敲：

```bash
# ===== 第一组：你在哪里？周围有什么？ =====

pwd
# 输出类似：/Users/你的用户名
# 这就是你的"当前位置"——终端打开后默认在家目录

ls
# 列出当前目录下的文件和文件夹
# 你会看到 Desktop、Documents、Downloads 等熟悉的文件夹

ls -la
# -l: 显示详细信息（权限、大小、修改时间）
# -a: 显示隐藏文件（以 . 开头的文件）

# ===== 第二组：到处走走 =====

cd ~
# 回到你的家目录

cd /
# 进入根目录——电脑文件的"起点"

ls
# 看看根目录下有什么
# 你会看到：bin etc home tmp usr var ... 等系统目录

cd ~/Desktop
# 进入桌面
# 试试 ls，看看是不是和你桌面上的文件一致

cd -
# 回到上一个目录（非常实用的快捷键）

# ===== 第三组：深入理解路径 =====

# 打开 Finder（或文件资源管理器），找到桌面上的一个文件
# 右键 → 显示简介（Mac）或 属性（Win），看看它的"位置"
# 然后在终端里用 cd 进入那个目录，用 ls 确认文件在那里
```

### 核心心法

> **路径就是文件的"地址"。** 在终端里，你就像拿着一个导航仪在文件系统里走。`pwd` 告诉你现在在哪，`ls` 告诉你周围有什么，`cd` 带你去想去的地方。

## 第 2 节：终端与 Linux 直觉

**视频**: [B 站链接](https://www.bilibili.com/video/BV1iaRRBHEgV) | **时长**: ~29 分钟

### 详细讲解

#### 2.1 终端到底是什么？

终端（Terminal）是另一种和电脑交互的方式。不是用鼠标点击图标和菜单，而是用文字——输入命令，回车执行。

```
图形界面：            终端：
┌──────────────┐    ┌──────────────┐
│ 点击文件夹图标 │    │ cd Desktop   │
│ 右键 → 新建   │    │ touch a.txt  │
│ 双击打开文件  │    │ open a.txt   │
└──────────────┘    └──────────────┘
```

**为什么学终端？** 因为服务器没有图形界面。没有桌面、没有文件夹图标、没有鼠标——只有黑底白字的终端。如果你不会终端操作，就等于进不了服务器的"门"。

#### 2.2 基本命令速查

| 命令 | 全称 | 作用 | 示例 |
|------|------|------|------|
| `pwd` | Print Working Directory | 显示当前位置 | `pwd` |
| `ls` | List | 列出文件 | `ls -la` |
| `cd` | Change Directory | 切换目录 | `cd ~/Desktop` |
| `mkdir` | Make Directory | 创建文件夹 | `mkdir project` |
| `touch` | — | 创建空文件 | `touch index.html` |
| `echo` | — | 输出文字 | `echo "hello"` |
| `cat` | Concatenate | 查看文件内容 | `cat index.html` |
| `cp` | Copy | 复制文件 | `cp a.txt b.txt` |
| `mv` | Move | 移动/重命名 | `mv old.txt new.txt` |
| `rm` | Remove | 删除文件 | `rm file.txt` |
| `man` | Manual | 查看命令手册 | `man ls` |

#### 2.3 Vim 生存指南

Vim 是服务器上默认的文本编辑器。它很难——难到有自己的"学习曲线"梗图。但你只需要掌握最少的操作就能活下来：

```
Vim 的三种模式：
┌─────────┐  按 i    ┌─────────┐  按 Esc  ┌─────────┐
│ 普通模式 │ ──────→ │ 编辑模式 │ ──────→ │ 普通模式 │
│ (移动光标)│ ←────── │ (输入文字)│ ←────── │          │
└─────────┘   Esc    └─────────┘         └─────────┘
      │                                       │
      │  输入 :                               │ 输入 :
      ▼                                       ▼
┌─────────┐                              ┌─────────┐
│ 命令模式 │                              │ 保存退出 │
│ :w 保存  │                              │ :wq      │
│ :q 退出  │                              │ :q! 不保存│
└─────────┘                              └─────────┘
```

**生存口诀**：
1. 按 `i` 开始打字
2. 打完按 `Esc`
3. 输入 `:wq` 保存退出

**够了。** 其他的以后慢慢学。

### 课堂演示代码

```bash
# ===== 第一组：文件操作 =====

mkdir ~/practice-folder
cd ~/practice-folder

touch hello.txt
echo "Hello World" > hello.txt
cat hello.txt
# 输出：Hello World

echo "第二行文字" >> hello.txt
# >> 表示追加，> 表示覆盖！注意区别！
cat hello.txt
# 输出两行

# ===== 第二组：复制和移动 =====

cp hello.txt copy.txt          # 复制
mv copy.txt renamed.txt        # 重命名
ls                             # 看到 renamed.txt

mkdir subfolder
mv renamed.txt subfolder/      # 移动到子文件夹
ls subfolder/                  # 看到 renamed.txt

# ===== 第三组：清理 =====

cd ~
rm -r practice-folder
# -r 表示递归删除（删除文件夹需要 -r）

# ===== 第四组：Vim 练习 =====

vim ~/test.txt
# 按 i → 输入 "我在用 Vim！"
# 按 Esc → 输入 :wq → 回车
cat ~/test.txt
# 应该看到你刚才输入的文字

rm ~/test.txt                  # 清理
```

## 第 3 节：互联网是怎么工作的

**视频**: [B 站链接](https://www.bilibili.com/video/BV1RA556qESY) | **时长**: ~20 分钟

### 详细讲解

#### 3.1 几个核心概念

**IP 地址**：互联网上的"门牌号"。每台联网设备都有一个 IP 地址。
- 格式：`123.45.67.89`（IPv4，4 组数字）
- 你的手机、电脑、服务器，各有一个 IP

**公网 IP vs 内网 IP**：
- 公网 IP：全球唯一，互联网上任何人都能找到
- 内网 IP：只在局域网内部有效（比如你家里的 WiFi 网络）

```
      你的电脑 (192.168.1.5)  ──── 路由器 (公网IP: 123.45.67.89) ──── 互联网
      你的手机 (192.168.1.6)  ────┘
      
      外人只能看到 123.45.67.89，不知道后面有几台设备。
```

**域名**：IP 的"文字版"，方便人类记忆。
- `bilibili.com` 就是 bilibili 服务器的 IP 的文字别名

**DNS**：自动把域名"翻译"成 IP 的系统。
```
你输入 bilibili.com → DNS 查询 → 返回 120.240.127.227 → 浏览器连接这个 IP
```

**端口**：IP 找到机器，端口找到机器上的具体程序。
```
IP: 123.45.67.89
  ├─ 端口 22  → SSH 服务（远程登录）
  ├─ 端口 80  → Web 服务（HTTP 网页）
  ├─ 端口 443 → Web 服务（HTTPS 加密网页）
  └─ 端口 3306 → MySQL 数据库
```

意思是：一台服务器上可以同时跑十几个程序，各个守着自己的端口。请求到了服务器之后，端口号决定了由哪个程序来处理。

#### 3.2 一次网页请求的完整旅程

```
步骤 1: 你在浏览器输入 https://www.bilibili.com
             │
             ▼
步骤 2: 浏览器问 DNS: "bilibili.com 的 IP 是多少？"
             │
             ▼
步骤 3: DNS 回答: "120.240.127.227"
             │
             ▼
步骤 4: 浏览器连接 120.240.127.227 的 443 端口
             │
             ▼
步骤 5: 服务器上的 Nginx（Web 服务）收到请求
             │
             ▼
步骤 6: Nginx 返回首页的 HTML 文件
             │
             ▼
步骤 7: 浏览器收到 HTML，渲染成你看到的页面
```

**这个过程通常只需要不到一秒钟。**

### 课堂演示代码

```bash
# 1. 查看你自己的 IP 地址
# macOS:
ifconfig | grep "inet "
# Windows:
ipconfig

# 2. 查看 DNS 解析结果
nslookup bilibili.com
# 你会看到 bilibili.com 对应的实际 IP 地址

# 3. 追踪数据包的路由（可能会被墙）
traceroute bilibili.com
# 你会看到数据包经过了哪些"中转站"才到达 bilibili 的服务器

# 4. 测试到 bilibili 服务器的延迟
ping -c 5 bilibili.com
# -c 5 表示发送 5 个包后停止
# time= 后面的数字越小，说明越近/越快
```

## 第 4 节：服务器、SSH 和 Nginx 实战（重点！）

**视频**: [B 站链接](https://www.bilibili.com/video/BV1ULLn62Eba) | **时长**: ~52 分钟

### 详细讲解

#### 4.1 服务器和你自己电脑的区别

| | 你的电脑 | 云服务器 |
|------|----------|----------|
| IP 地址 | 内网 IP（别人找不到你） | 公网 IP（全球可访问） |
| 操作系统 | macOS / Windows | 通常是 Linux（Ubuntu） |
| 图形界面 | 有桌面、窗口 | 只有终端（黑底白字） |
| 运行状态 | 晚上会关机 | 24 小时不关机 |
| 硬件 | 有屏幕、键盘、音响 | 可能只有一个主机盒子，甚至只是一块电路板 |
| 配置 | 通常较高 | 可以很低，最便宜的一年几十块 |

#### 4.2 买服务器要关注什么？

**抓住这几个点就够了**：

1. **买的是服务器**（有的叫"云服务器 ECS"或"轻量应用服务器"），不是数据库、不是 CDN、不是对象存储
2. **操作系统选 Ubuntu**（推荐 24.04 LTS）
3. **配置选最低档**。2 核 2G 够用，1 核 1G 也能跑
4. **确认有公网 IP**

> 关于价格：阿里云、腾讯云经常有活动价。双 11、618 之类的时候，99 元/年就能拿下一台 2 核 2G 的服务器。平时价格会高一些。

#### 4.3 买完之后你拿到的三样东西

| 信息 | 说明 | 示例 |
|------|------|------|
| 公网 IP | 服务器的地址 | `123.45.67.89` |
| 用户名 | 登录用的账号 | `ubuntu` 或 `root` |
| 密码 | 登录密码 | 你自己设置的，或云厂商生成的 |

**记好这三样东西！** 忘了密码可以在云平台控制台重置。

#### 4.4 SSH 是什么？

SSH（Secure Shell）是远程登录 Linux 服务器的标准方式。它建立一条加密的通道，让你能安全地在远程服务器上执行命令。

**注意**：SSH 默认监听 **22 端口**。所以你需要确保云服务器的安全组（防火墙）放行了 22 端口的入站流量。

#### 4.5 `sudo` 和 `apt`

- `sudo` = "以管理员身份执行"（Super User DO）
  - 类比：Windows 上右键 → "以管理员身份运行"
  - 不是所有命令都需要 `sudo`，只有涉及系统配置、安装软件时才需要
  
- `apt` = Ubuntu 的软件包管理器（Advanced Package Tool）
  - 类比：macOS 的 Homebrew，手机的"应用商店"
  - `apt update` = 刷新软件列表
  - `apt install xxx -y` = 安装软件（`-y` 跳过确认提示）

#### 4.6 Nginx 是什么？

Nginx（发音：Engine-X）是一个高性能的 Web 服务器。它的核心工作就是：

> **在某个端口上守着，有人来请求了，就返回对应的文件。**

Nginx 能做的事情远不止这些（反向代理、负载均衡、限流等），但现在你只需要知道它最基本的用途：**让服务器能对外提供网页**。

#### 4.7 完整实操步骤（逐行跟做）

```bash
# ========================================
# 第一步：买服务器（在浏览器操作，不在终端）
# ========================================
# 1. 打开阿里云/腾讯云/华为云任意一家的网站
# 2. 找到"云服务器 ECS"或"轻量应用服务器"
# 3. 点击购买
# 4. 关键配置：
#    - 地域：选离你最近的（延迟低）
#    - 镜像/操作系统：Ubuntu 24.04 LTS
#    - 实例规格：选最低配（1核1G 或 2核2G）
#    - 网络：选择"分配公网 IPv4 地址"
# 5. 设置密码（记住！）
# 6. 确认下单，付款
# 7. 等待 1-3 分钟，服务器启动

# ========================================
# 第二步：配置安全组（在云平台控制台操作）
# ========================================
# 找到"安全组"或"防火墙"设置
# 确认以下端口已开放（入站规则）：
#   - 22 端口（SSH，用于远程登录）
#   - 80 端口（HTTP，用于网页访问）
# 如果没有，点击"添加规则"新建

# ========================================
# 第三步：SSH 登录（在你的终端操作）
# ========================================

# 基本格式：
# ssh 用户名@服务器IP
ssh ubuntu@123.45.67.89
#    ↑      ↑
#    │      └─ 换成你的服务器公网 IP
#    └─ 用户名，一般是 ubuntu

# 首次连接会提示：
# The authenticity of host 'xxx' can't be established.
# Are you sure you want to continue connecting (yes/no)?
# 输入 yes 然后回车

# 输入密码（输入时不显示任何字符，是正常的！）
# 登录成功后，提示符会变成：
ubuntu@你的服务器主机名:~$

# ========================================
# 第四步：在服务器上试试命令
# ========================================

pwd
# /home/ubuntu  ← 你在服务器上的"家目录"

ls
# 空空如也——这是一台全新的机器

whoami
# ubuntu  ← 你是谁

cd / && ls
# 探索根目录：bin boot dev etc home lib ...
# 跟你的 macOS 完全不一样，
# 因为这是 Linux，另一套操作系统

# ========================================
# 第五步：更新软件列表
# ========================================

sudo apt update
# 输入你的服务器密码（和 SSH 密码一样）

# ========================================
# 第六步：安装 Nginx
# ========================================

sudo apt install nginx -y

# 确认安装成功：
nginx -v
# nginx version: nginx/1.24.0 (Ubuntu)

# 确认 Nginx 正在运行：
sudo systemctl status nginx
# 找到这一行：
# Active: active (running) ← 说明正在运行！

# 如果显示 inactive，手动启动：
sudo systemctl start nginx

# ========================================
# 第七步：浏览器访问！
# ========================================

# 打开你自己的浏览器，输入：
http://你的服务器公网IP

# 如果看到 "Welcome to nginx!" 的默认页面
# 恭喜你！你的服务器已经能对外提供网页了！

# 如果打不开：
# 1. 检查安全组是否放行了 80 端口（入站规则，TCP 协议）
# 2. 检查 Nginx 是否真的在运行（systemctl status nginx）
# 3. 检查 IP 地址是否输入正确

# ========================================
# 第八步：找到那个默认页面
# ========================================

# 查看 Nginx 配置：
cat /etc/nginx/sites-available/default

# 在一堆文字中找到这一行：
# root /var/www/html;
# 这表示 Nginx 会从 /var/www/html 目录里找网页文件

# 去那个目录看看：
cd /var/www/html
ls
# 应该看到 index.nginx-debian.html

# 查看它的内容：
cat index.nginx-debian.html
# 这就是浏览器里那个页面的源代码！

# ========================================
# 第九步：修改它！
# ========================================

# 用 Vim 编辑：
sudo vim /var/www/html/index.nginx-debian.html

# Vim 操作流程：
# 1. 按 i（进入编辑模式）
# 2. 用方向键移动光标
# 3. 找到最显眼的一行英文，把它改成：
#    <h1>你好，这是我改的页面！</h1>
# 4. 按 Esc（退出编辑模式）
# 5. 输入 :wq（保存并退出）
# 6. 按回车

# 刷新浏览器，你应该能看到自己改的文字了！

# ========================================
# 关键总结：你刚才走完的完整链路
# ========================================
# 浏览器 → 公网IP → 服务器的80端口 → Nginx
# → 读取 /var/www/html/xxx.html → 返回文件内容 → 浏览器显示
```

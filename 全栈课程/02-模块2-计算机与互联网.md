## 第 1 节：认识你的电脑

**视频**: [2.1](https://www.bilibili.com/video/BV1zcRhBsEob) | **时长**: ~19 分钟  
**配套课件**: https://xn--ygr25xpohxwz.com/zero-to-fullstack/lessons/module-2-1/

### 知识点

| 知识点 | 说明 |
|--------|------|
| 文件系统 | 电脑里的文件是怎么组织的——文件夹（目录）的树状结构 |
| 路径 | 绝对路径 vs 相对路径；`/` vs `\` |
| 什么是"在电脑里工作" | "会用软件"和"会在电脑里工作"不是一回事 |
| 根目录与家目录 | `/` 和 `~/` 的区别 |

### 实操练习

```bash
# 打开终端（Terminal），尝试以下命令
pwd          # 查看当前所在目录
ls           # 列出当前目录下的文件
ls -la       # 列出所有文件（包括隐藏文件）
cd ~         # 回到用户家目录
cd /         # 进入根目录
cd -         # 回到上一个目录
```

### 关键概念

> **路径**就是文件夹的地址。绝对路径从根目录 `/` 开始写，相对路径从当前位置开始写。
>
> 类比：绝对路径 = "广东省广州市天河区体育西路 123 号"；相对路径 = "往前走两个路口右转"。

## 第 2 节：终端与 Linux 直觉

**视频**: [2.2](https://www.bilibili.com/video/BV1iaRRBHEgV) | **时长**: ~29 分钟  
**配套课件**: https://xn--ygr25xpohxwz.com/zero-to-fullstack/lessons/module-2-2/

### 知识点

| 知识点 | 说明 |
|--------|------|
| 终端是什么 | 只是另一种和电脑交互的方式（没有图形界面的操作方式） |
| 命令行 vs 图形界面 | 图形界面 = 用鼠标点；终端 = 用文字指挥 |
| 为什么学终端 | 服务器没有图形界面，只能通过终端操作 |
| 基础命令 | `pwd`、`ls`、`cd`、`mkdir`、`touch`、`cp`、`mv`、`rm`、`cat` |
| Vim 生存指南 | `i` 进入编辑；`Esc` 退出编辑；`:wq` 保存退出；`:q!` 不保存退出 |

### 实操练习

```bash
mkdir ~/test-folder       # 创建文件夹
cd ~/test-folder          # 进入文件夹
touch hello.txt            # 创建空文件
echo "Hello World" > hello.txt   # 写入内容
cat hello.txt              # 查看文件内容
cp hello.txt copy.txt      # 复制文件
mv copy.txt renamed.txt    # 重命名/移动文件
rm renamed.txt             # 删除文件
cd .. && rm -r test-folder # 返回上级并删除测试文件夹
```

### Vim 最小生存操作

```bash
vim test.txt    # 打开/创建文件
# 按 i         → 进入编辑模式
# 输入一些文字
# 按 Esc       → 退出编辑模式
# 输入 :wq     → 保存并退出
# 按回车
```

## 第 3 节：互联网是怎么工作的

**视频**: [2.3](https://www.bilibili.com/video/BV1RA556qESY) | **时长**: ~20 分钟  
**配套课件**: https://xn--ygr25xpohxwz.com/zero-to-fullstack/lessons/module-2-3/

### 知识点

| 知识点 | 说明 |
|--------|------|
| IP 地址 | 互联网上的"门牌号"，每台联网设备都有的数字地址 |
| 公网 IP vs 内网 IP | 公网 IP 全球唯一，内网 IP 只在局域网内有效 |
| 域名 | IP 地址的"文字别名"——比如 `bilibili.com` |
| DNS | "域名 → IP"的翻译系统，就像电话本 |
| 端口 | IP 找到机器，端口找到机器上的具体程序 |
| 服务器 | 本质上就是一台联网的电脑，但有公网 IP，24 小时不关机 |
| 浏览器的工作流程 | 浏览器 → DNS 解析 → 服务器 IP → 端口 → Nginx → 返回页面 |

### 课堂讨论

1. 你在浏览器输入 `bilibili.com` 按下回车后，到页面显示出来，中间发生了什么？
2. 为什么你的手机连着 WiFi 可以上网，但别人不能直接访问你手机上的文件？

### 核心链路

```
浏览器 → 域名解析（DNS）→ 服务器公网 IP → 80/443 端口 → Web 服务 → 返回 HTML → 浏览器渲染
```

## 第 4 节：服务器、SSH 和 Nginx 实战

**视频**: [2.4](https://www.bilibili.com/video/BV1ULLn62Eba) | **时长**: ~52 分钟  
**配套课件**: https://xn--ygr25xpohxwz.com/zero-to-fullstack/lessons/module-2-4/

### 知识点

| 知识点 | 说明 |
|--------|------|
| 服务器 vs 个人电脑 | 有公网 IP、无显示器、一直开机、跑 Linux |
| 云服务器 | 云厂商托管硬件，你按配置付费，远程操控 |
| Ubuntu | 最主流的服务器 Linux 发行版 |
| SSH | 远程登录 Linux 服务器的标准方式 |
| `ssh 用户名@IP` | 从你的终端登录远程服务器 |
| `apt` | Ubuntu 的软件安装工具 |
| Nginx | 高性能 Web 服务器，监听端口、返回网页 |
| 防火墙/安全组 | 控制哪些端口对外开放 |

### 实操步骤

#### 1. 租用云服务器

- 任选云厂商（腾讯云、阿里云、华为云等）
- 操作系统选 **Ubuntu 24.04 LTS**
- 配置选最低档即可
- 确认机器有公网 IP
- 设置密码，记录：**公网 IP、用户名（通常是 `ubuntu` 或 `root`）、密码**

#### 2. 安全检查组/防火墙

- 确保 **22 端口**（SSH）开放
- 后续需要开放 **80 端口**（HTTP）

#### 3. SSH 登录

```bash
ssh ubuntu@你的公网IP
# 首次连接输入 yes
# 输入密码（不会显示任何字符，这是正常的）
```

#### 4. 在服务器上运行基本命令

```bash
pwd                    # 确认当前位置
ls                     # 查看当前目录
cd / && ls              # 探索根目录结构
```

#### 5. 安装 Nginx

```bash
sudo apt update
sudo apt install nginx -y
systemctl status nginx   # 确认 Active: active (running)
```

#### 6. 浏览器访问

- 确保 80 端口在安全组中已放行
- 浏览器打开 `http://你的公网IP`
- 应该看到 Nginx 默认欢迎页

#### 7. 找到并修改默认页面

```bash
cat /etc/nginx/sites-available/default   # 查看配置，找到 root 路径
# 通常 root /var/www/html;
cd /var/www/html && ls
sudo vim index.nginx-debian.html
# i → 修改内容 → Esc → :wq → 回车
```

刷新浏览器，看到你改的内容！

### 完整链路回顾

```
浏览器 → 公网 IP → 服务器的 80 端口 → Nginx → /var/www/html/xxx.html → 返回 → 浏览器显示
```

### 常见卡点

| 问题 | 解决方向 |
|------|----------|
| SSH 连不上 | 检查用户名是否正确、密码是否输对、22 端口是否开放 |
| 浏览器打不开 IP | 检查安全组是否放行 TCP 80 端口入站流量 |
| Nginx 状态不是 `active` | `sudo systemctl start nginx` |
| Vim 改了没生效 | 确认按了 `Esc` → `:wq` → 回车 |

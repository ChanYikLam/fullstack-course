## 基础题（必做）

### 1. 概念理解

用自己的话解释以下三个问题（每个不少于 100 字）：

- 什么是"全栈开发"？
- 为什么在 AI 时代学习全栈开发反而更有意义？
- "管理代码"和"写代码"有什么区别？

### 2. 环境准备（截图验证）

- [ ] 安装 VS Code，打开后截图
- [ ] 打开终端（Mac：Terminal / Win：PowerShell），输入 `whoami` 截图
- [ ] 注册 GitHub 账号，截图个人主页

### 3. 课程预期

学完这门课之后，你最想做出一个什么样的产品？写一段产品构想（不限字数）。

---

## 进阶题（选做）

### 4. 探索 VS Code

- 安装 VS Code 后，尝试安装一个插件（比如 "Chinese (Simplified) Language Pack" 中文语言包）
- 在 VS Code 里新建一个文件，随意写点内容，保存为 `.md` 文件（Markdown 格式）
- 按 `Ctrl+Shift+V`（Mac: `Cmd+Shift+V`）预览 Markdown 效果

### 5. 了解 Markdown 语法

在网上搜索 "Markdown 语法"，学习以下基本语法：
- 标题（`# ## ###`）
- 加粗（`**文字**`）
- 列表（`- 项目`）
- 链接（`[文字](网址)`）
- 代码块（` ``` 代码 ``` `）

用 Markdown 写一篇短文介绍自己，保存为 `自我介绍.md`。

### 6. 思考题

- 你在生活中使用过哪些"前端"产品？（网站、App 等）
- 你觉得这些产品背后有没有"后端"？试着猜一猜后端在做什么。
- 找一个你喜欢的网站，按下 F12（或右键 → 检查），随意看看里面有什么。你看到了什么有趣的东西？

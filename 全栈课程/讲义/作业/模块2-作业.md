### 4. 自由探索

在服务器上，进入根目录 `/`，用 `ls` 查看每个子目录，记录你觉得有趣的目录名。用 `man hier` 或搜索引擎了解它们的用途。

### 5. 命令行练习

学习并使用以下新命令：`head`、`tail`、`wc`、`grep`

创建一个有 20 行文字的文本文件，分别用：
- `head -n 5` 看前 5 行
- `tail -n 5` 看后 5 行
- `wc -l` 数行数

### 6. Vim 进阶

- `dd`——删除一行

## 挑战题

### 7. 端口实验

在服务器上用 Python 启动一个简单的 HTTP 服务：

```bash
cd /tmp
echo "<h1>Hello from Python</h1>" > index.html
python3 -m http.server 8080
```

- 在云平台安全组中放行 8080 端口
- 浏览器访问 `http://你的IP:8080`
- 思考：这和 Nginx 有什么不同？

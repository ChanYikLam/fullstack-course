# 模块 7：项目实战 — 课后作业

## 基础题（必做）

### 1. 项目规划练习

选择一个你想做的应用（Todo、记账、读书笔记、食谱管理...），**只画图纸，不写代码**。提交以下四样：

1. **功能列表**：这个应用要能做什么？
2. **页面树**：有哪些页面？URL 各是什么？
3. **数据模型**：数据库有哪些表？字段各是什么？表之间怎么关联？
4. **API 列表**：每个接口的方法、路径、请求体、响应体

### 2. 用户系统

实现完整的用户系统接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/auth/register` | POST | 注册（密码 bcrypt 哈希） |
| `/api/auth/login` | POST | 登录（返回 JWT token） |
| `/api/auth/me` | GET | 获取当前用户信息（需认证） |

要求：
- 密码使用 bcrypt 哈希，不存明文
- Token 使用 JWT
- 正确的错误处理（用户名已存在、密码错误、token 过期）

### 3. CRUD 实现

选一个资源（文章/笔记/事项），实现完整的 CRUD 接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/xxx` | GET | 列表（含分页 `?page=1&size=10`） |
| `/api/xxx/:id` | GET | 详情 |
| `/api/xxx` | POST | 创建（需认证） |
| `/api/xxx/:id` | PUT | 更新（需认证 + 所有权验证） |
| `/api/xxx/:id` | DELETE | 删除（需认证 + 所有权验证） |

要求：
- 分页返回 `{items, total, page, size, pages}`
- 权限验证：只有创建者能修改/删除自己的数据
- 创建/更新时校验数据（长度、必填、类型）

## 进阶题（选做）

### 4. 文件上传

实现文件上传接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/upload` | POST | 上传文件，返回可访问的 URL |

要求：
- 校验文件类型（白名单：jpg/png/gif/webp）
- 校验文件大小（限制 5MB）
- 生成唯一文件名（防止覆盖）
- 前端实现文件选择和预览

### 5. 项目重构

将你的项目从"全写在一个文件"重构为以下结构：

```
backend/
├── main.py            —— FastAPI 入口
├── config.py          —— 配置（数据库地址、密钥等，从环境变量读取）
├── database.py        —— 数据库连接和会话管理
├── models/
│   └── models.py      —— SQLAlchemy 模型
├── schemas/
│   └── schemas.py     —— Pydantic 请求/响应模型
├── routers/
│   ├── auth.py        —— 认证相关路由
│   └── resources.py   —— 资源 CRUD 路由
├── services/
│   ├── auth_service.py
│   └── resource_service.py
└── utils/
    └── logger.py      —— 日志配置
```

## 挑战题

### 6. 完整博客系统

实现一个完整的个人博客系统：

**功能要求**：
- 用户注册/登录
- 文章 CRUD（标题、内容、封面图）
- 评论功能（发表、列表、删除）
- 管理员后台（管理自己的文章和评论）

**技术要求**：
- 前后端分离（React/Next.js + FastAPI）
- JWT 认证
- 文件上传（文章封面图）
- 分页
- 部署到服务器，公网可访问

**产出要求**：
- GitHub 仓库（含 README 说明如何运行）
- 公网可访问的链接

### 3. 手搓 API

用 `http.server` 手写一个 API 服务器，包含两个接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/status` | GET | 返回 `{"status": "ok", "time": "当前时间"}` |
| `/api/echo?message=xxx` | GET | 返回 `{"echo": "xxx"}` |

要求：
- 使用 `http.server.BaseHTTPRequestHandler`
- 正确设置 `Content-Type: application/json`
- 处理 404
- 用 `curl -v` 查看完整报文并截图

### 4. FastAPI 迁移

用 FastAPI 重写上面两个接口，并添加一个 POST 接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/messages` | POST | 接收 `{"name": "...", "content": "..."}`，返回 `{"id": 1, "name": "...", "content": "..."}` |

要求：
- 自动文档 `/docs` 能正常访问
- 用 `curl` 测试 POST 接口

## 挑战题

### 7. MVC 结构

将 FastAPI 项目拆分成多文件结构：

```
backend/
├── main.py              —— FastAPI 入口（创建 app）
├── routers/
│   ├── status.py        —— /api/status 相关路由
│   └── messages.py      —— /api/messages 相关路由
├── models/
│   └── schemas.py       —— Pydantic 模型
└── services/
    └── message_service.py —— 业务逻辑
```
